## 🚀 Проекты

### 💰 BudgetLight

Android-приложение для планирования личного бюджета с собственным backend.

**Стек:** Kotlin, Jetpack Compose, Clean Architecture, MVVM, Hilt, Room, Coroutines/Flow, Ktor Client, Ktor, PostgreSQL.

* Feature-based архитектура
* Регистрация и авторизация через JWT
* Локальное хранение финансовых данных
* Backend API и серверная авторизация
* Unit и интеграционные тесты

[GitHub →](https://github.com/LampJuice/Budgetlight)

### 🔎 Vacancy Search

Приложение для поиска вакансий с использованием API.

**Стек:** Kotlin, XML, Koin, Retrofit, Clean Architecture.

* Поиск и фильтрация вакансий
* Работа с REST API
* Сохранение настроек фильтров
* Разделение на слои data / domain / presentation

[GitHub →](https://github.com/LampJuice/vacancy-search)

### 🛒 Shopping List

Приложение для создания и управления списками покупок.

**Стек:** Kotlin, Android, MVVM, Room.

* Создание и редактирование товаров
* Локальное хранение данных
* Работа с базой данных Room

[GitHub →](https://github.com/LampJuice/ShoppingList-Android)

### 🎵 Playlist Maker

Приложение для поиска музыки и работы с iTunes API.

**Стек:** Kotlin, Android, Retrofit, MVVM.

* Поиск треков через iTunes API
* История поиска
* Работа с сетевыми запросами
* Обработка состояний UI

[GitHub →](https://github.com/LampJuice/PlaylistMaker)

### 🕒 ShiftTracker

Приложение для учёта рабочих смен.

**Стек:** Kotlin, Android, MVVM, Room.

* Учёт рабочих смен
* Локальное хранение данных
* Расчёт рабочего времени

[GitHub →](https://github.com/LampJuice/ShiftTracker)
